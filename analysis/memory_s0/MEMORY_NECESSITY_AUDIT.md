# S0 任务三:Memory 必要性审计(决策点级)

> 生成:2026-10-08 | 性质:只读审计(无新实验;证据=既有 stage 产物 +
> 源码 + 轨迹目录)
> 审计标准:一个决策点构成 **Memory 必要**,当且仅当
> ① 正确决策所需的信息在**当前观测 + 任务指令**中不可得;
> ② 该信息可由**交互历史**补足(历史上曾被观测到);
> ③ 不存在不依赖记忆的替代信息来源。
> **三条禁令**(预注册级约束,逐条自查):
> 禁把"任务长"认定为必要;禁把"执行失败"认定为必要;
> 禁把"记忆被读取/注入"认定为必要。

## 一、候选决策点清单(从代码 + 既有轨迹归纳)

以下 9 个决策点覆盖了当前 HarnessVLA(LIBERO spatial t3/t5/t9 +
Pi0.5 + SAM3 + Planner)在一条 episode 里发生的全部决策类别,以及
系统侧的记忆决策。逐项审计见第二节表。

| # | 决策点 | 发生时刻 | 决策者 |
|---|---|---|---|
| DP-1 | 下一步技能选择(pick/place/move_to/…) | 每 turn | Planner |
| DP-2 | 感知先行 vs 直接行动(调 segment/back_project 还是直接抓) | 行动前 | Planner |
| DP-3 | 抓取目标消歧(多同类物体选哪个:t9 多 bowl 场景) | 抓取前 | Planner |
| DP-4 | 失败检测与重试决策(重试同一技能 vs 放弃) | 工具返回错误后 | Planner |

## 二、逐决策点审计表

列:当前可观测 / 缺失的历史信息 / 正确决策为何需要历史(或为何不需要)/
替代信息来源 / 轨迹或代码证据 / 判定。

### DP-1 下一步技能选择

- **当前可观测**:当前帧图像(agentview+wrist)、view_driver_state
  (机器人状态/上一步 result,`robots/libero/tools.py:1604`)、任务指令。
- **缺失的历史信息**:无结构性缺失。episode 内上一步结果已在
  view_driver_state 的 command log 中(近因可见);更早历史对
  "下一步选哪个原语"无决策价值(原语选择由当前场景形态决定)。
- **为何不需要历史**:LIBERO 单指令任务的技能序是场景驱动
  (看见目标未抓 → pick;已抓 → place),当前帧 + 指令足够。
- **替代来源**:当前观测本身;PhaseTracker 进度相位
  (`rpent/memory/structured.py:97`,episode 内状态,非持久记忆)。
- **证据**:Stage A 全量审计 —— 触发 0/120、决策时刻记忆回查 0
  (`analysis/memory_stageA_results.md`);Stage H 在线消融 ——
  无记忆内容的进度触发臂 P2 SR 83.3 反而高于 GRAPH 76.7 与
  CARD 66.7(DECISIONS/Stage H 结论,commit 22aca81)。
- **判定:非历史必要**(证据为"内容无增量",非"没读过"而已 ——
  H 是正面对照)。

### DP-2 感知先行 vs 直接行动

- **当前可观测**:图像质量、分辨率、上一次感知工具返回(SAM3 score、
  back_project 坐标)—— 均在工具结果流中(planner 可见)。
- **缺失的历史信息**:无。"上次 segment 分数低"是近因,单步可见。
- **替代来源**:工具结果流(view_driver_state result 字段)。
- **证据**:卡片中 perception 类 13 张全部描述"何时该用腕视野/重分割"
  类规则,其条件词(sam3 low score、occluded)本就出现在当前工具
  返回里 —— Stage D 审计发现这批卡的症状词与检索 query 词面交集为空
  (D1/C1 机制结论),且补 468 条别名仍无区分度
  (`analysis/memory_staged_results.md`,commit f9e4cb1)。
- **判定:非历史必要**(该决策需要的是当前感知质量信号,已可见)。

### DP-3 抓取目标消歧(最接近"需要记忆"的候选)

- **当前可观测**:agentview 全局布局 + wrist 近距细节 + 指令语言指涉
  ("the black bowl on the wooden cabinet",见 Stage R 事件 prompt)。
- **缺失的历史信息(假设性)**:若两个同类物体外观不可分、且指令
  无区分词,则需要"哪个是之前动过的"这类历史。**但**:t3/t5/t9 的
  指令均带语言区分词(颜色/位置/容器);指令本身的指涉在当前帧可解。
- **为何不需要历史**:消歧信息在指令+当前帧内;Stage K 对照实验里
  B0(state-only,无任何历史表征)全指标最优,加 DINOv2 历史表征
  为负贡献(Stage K 结论,commit bfc2aac)—— 消歧决策上历史表征
  是被正面排除的。
- **替代来源**:指令语言 + 当前帧;SAM3 mask + back_project。
- **证据**:Stage K 终报(K1 门 FAIL→STOP);Stage A perception
  检索全条件 0/17(`analysis/memory_stageA_results.md`)。
- **判定:非历史必要**。注:这是六参考系统里 Ledger/SimpleARM 用
  记忆解决的场景类型,但**在当前任务族中该场景未被构造** —— 指令
  都带区分词。任务族属性,非机制否定。

### DP-4 失败检测与重试决策

- **当前可观测**:工具错误返回(pick 失败码)、图像(没抓起来)、
  episode 内连败计数(PhaseTracker 已有同构能力:moves_since_pick、
  错误计数,`structured.py:120-127`)。
- **缺失的历史信息**:无 —— 重试决策需要的是"已试几次"计数,
  是 **episode 内可重算状态**,不是跨 episode 记忆。
- **为何不需要(持久)记忆**:Stage R 谱系给出正面证据:失败多为
  瞬态(E14/24 EPHEMERAL,重采样即解),对瞬态失败"再试一次"
  不需要任何历史;对持久失败(P5/24,全 t9),同动作重放与策略
  重采样 8 次全败(q_same mean .302 ≈ q_policy .323)—— 历史
  信息不改变动作分布本身。
- **替代来源**:episode 内计数器(已实现)+ 重采样机制本身。
- **证据**:`analysis/STAGE_R_FINAL_REPORT.md`(六判定;
  h(k) 连败 3 次后第 4 次 1/17、第 8 次 0/11 —— 连败历史带来的
  是"停止重试"的预算决策,而该历史就在当前 episode 内,无需持久记忆)。
- **判定:伪需求排查成立 —— 非持久记忆必要**("执行失败"禁令的
  正面案例:失败≠需要记忆)。

### DP-5 持久失败后的换法/放弃决策

- **当前可观测**:当前失败模式(错误码、图像)、episode 内连败计数。
- **缺失的历史信息(假设性)**:"上次这个任务也这样失败、换 X 方法
  成功了" —— 跨 episode 经验,恰是 43 张 strategy 卡的内容。
- **为何实际不需要**:① 该决策在本系统被预算机制(turn budget 40)
  和 Stage R 证据处理:h(k) 显示连败后成功概率趋零,正确决策是
  "停止",而停止信号来自 episode 内计数;② 跨 episode 经验的线上
  消费被系统性审计为 0(Q0 审计:memory 路径 100% 断、卡片触达 16%、
  **决策时刻回查 0**,`analysis/memory_q0_audit.md`);③ Stage P
  正面测试恢复候选选择:verifier 无头寸(O@8−O@1=10pp<15pp 门)、
  TEST 9/10 首候选即恢复 —— "选哪个恢复法"这个决策本身几乎没有
  信息需求。
- **替代来源**:episode 内计数 + 预算 + 候选接口(Stage P 已证够用)。
- **证据**:Q0 审计 + Stage P 终报(TEST 9/10)+ Stage R h(k)。
- **判定:非历史必要**(且有"内容存在但无消费者"的系统性证据)。

### DP-6 恢复候选/方法选择

- 同 DP-5 后半:Stage P 已冻结 —— candidate interface qualified,
  selection/verifier 无 headroom。首候选即恢复 9/10。
- **判定:非历史必要**(决策空间退化为"试第一个就够")。

### DP-7 finish 时机

- **当前可观测**:当前帧(任务目标是否达成,如图中碗已在筐里)+
  view_driver_state。planner 无 check_success 真值(防火墙),
  靠图像自判。
- **缺失的历史信息**:无 —— 过早收尾问题(attributeagent R22-T 的
  "回归=过早收尾"教训同源)是**当前观测判读**问题(图里没看清就
  收),补历史无益:上一步的历史图像同样是图,判读难度不变。
- **替代来源**:更仔细的当前帧判读(wrist 视野复查);B2 verifier
  已实现过程裁决但结论是"裁决不驱动行为"(B2 STV,无动作级杠杆)。
- **证据**:Stage L term 型失败机制发现(commit e42ddb3);
  Stage H guard 90% 违规 = 建议无动作级杠杆(22aca81)。
- **判定:非历史必要**。

### DP-8 记忆注入时机与内容(系统侧)

- 说明:这是系统自身的决策,不构成"任务需要记忆"的证据(禁令三:
  记忆被读取≠必要)。记录机制结论:注入的唯一正收益来自**触发
  时机**(进度信号 R1-R5 的 timing),Stage C 组合臂 SR .733→.852
  的增益与内容无关 —— 因为内容侧对照(Stage D/E/F0)全部失败:
  468 别名无区分度、溯源 NOT SUPPORTED、typed address 上界不足。
- **证据**:`analysis/memory_stageC_results.md`(三判定:QUERY 否 /
  PROGRESS 是 / 组合 是)+ Stage D/E/F0 终报。
- **判定:该决策点的收益归因于 episode 内进度信号,非记忆内容 ——
  不构成必要性**。

### DP-9 遮挡/移出视野后的对象重认(部分可观测补偿)

- **当前可观测**:遮挡后当前帧无目标信息(如柜内物体)。
- **缺失的历史信息(假设性)**:"物体最后一次被看到时在哪" ——
  理论上是记忆的标准用例(SimpleARM reference 类状态)。
- **为何实际不成立(在本任务族)**:① Stage L 机制发现:该场景下
  "感知死"—— 物体位置在 planner 可见通道中**从未被观测到**
  ( Stage L:位置不可观测;commit e42ddb3)。历史中同样没有该信息
  —— 记忆无法补足从未进入观测通道的内容;② Stage N:65% realized
  但 0/144 recovery —— 失败虽可实现,历史信息未转化为任何恢复;
  ③ Stage K:B0 state-only 全优,VERIFIED 全集中 FG-3。
- **替代来源**:无(这是传感/观测通道问题,不是记忆问题 ——
  修复方向是感知,不是记忆)。
- **证据**:Stage K/L/N 终报(commits bfc2aac / e42ddb3 / 369220e)。
- **判定:非记忆问题(观测通道缺陷,历史无从补足)**—— 这是最
  接近"需要历史"的点,被三个 stage 的证据合力排除。

## 三、三禁令自查(逐条)

1. **"任务长"≠必要**:LIBERO episode ≤40 turns,进度全程可观测
   (PhaseTracker 已实现跟踪);无跨时程目标栈。✔ 未采信。
2. **"执行失败"≠必要**:Stage R 谱系正面处理 —— 瞬态失败(E14/24)
   重采样即解(无需历史);持久失败(P5/24)重采样与历史都不可解
   (q_same≈q_policy;h(k)→0)。失败的存在不构成任何历史信息需求。✔ 未采信。
3. **"记忆被读取"≠必要**:Stage C 组合臂收益经 Stage D/E/F0/H 内容侧
   对照分解,归因于触发时机;且 Q0 审计显示决策时刻回查本就是 0。✔ 未采信。

## 五、审计结论

**在当前任务族(LIBERO spatial t3/t5/t9,单指令、≤40 turns、指令带
语言区分词、sim 真值防火墙)与当前系统(任务二能力清单)下:未找到
任何满足三条件标准的决策点。**

- 9 个决策点全部落位:6 个当前观测可解、2 个 episode 内状态可解
  (计数/进度,已有实现)、1 个是观测通道缺陷(历史无从补足)。
- 唯一拿过正收益的机制(Stage C)收益归因于 episode 内进度触发,
  与跨 episode 记忆内容无关。
- 因此对"当前 HarnessVLA 中 Memory 究竟在哪些决策点具有不可替代
  作用"的回答是:**没有** —— 且这是**任务族属性**(历史依赖场景
  未被构造),不是 Memory 概念的一般否定:参考系统(SimpleARM
  RoboMME +22.7pp、BATON +11.6%)在专门构造历史依赖的任务上
  有大效应,其机制(条件检索 + typed state + 对象账本)在任务一
  对照表中均可查。

**判定(供 S0_RESEARCH_DECISION.md 正式采用):
MEMORY NECESSITY: NOT SUPPORTED(限定于当前任务族与观测设计)。**
