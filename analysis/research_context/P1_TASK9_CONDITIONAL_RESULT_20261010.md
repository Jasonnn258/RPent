   零拟合)在 Top20% 即可达期望 **14.5/21=0.69**(2.72× 随机)。这是 L1 保留的唯一

   三臂全正)但量小且统计脆弱(区间跨 0)——只能在**独立新 cohort + 独立持握标签**上
   确认,不存在任何部署增益宣称。

   (受控提升 probe / 腕视目标在场-跟随),即 D-035 分支 B 的合同;需用户有界 L2 授权。

### 3.1 · 后续可执行性限定（2026-10-10 独立复查）

**这里的“Task×Gate matched = 14.48/21 ≈ 0.69”是事后随机对照期望，不是已实现的独立任务预算策略。** `p1_triage_incremental_lab.py:decompose` 首先调用 `select_weights(rows, "LIFT_MINUS_GAP", .20)` 得到 LMG 实际选中权重，再依照权重合计锁定 task×gate 的选中配额，最后从同一批 audit-only FGONLY 标签计算单元格正例率。该计算适用于拆解 **LMG 已观察到的 17/21**，但不能证明无监督预先选择名额的 gate+task 策略可取得 14.48 期望。

因此原文 §3 第1点中的“零拟合即14.5/21=0.69”应读作**组成匹配对照的回顾性期望**，**不得当成可部署预算器的实测性能**。当前具有完整固定标签盲规则的低成本主基线是 `D_ONLY_PATTERN` Top20% 13.26/21≈0.632。Task ID 来自 `A_reconstruction_metadata`，尚未证实 Harness pre-delivery 判定点可合法读取，也尚未证明在线可以提前知道完整复核池大小。下一组独立 `p1_label_blind_quota_lab.py`（文档 `P1_LABEL_BLIND_QUOTA_EXPERIMENT.md`）已提交但**服务器尚未运行**，会验证独立可生成预算的方案；不会修改前述原始观测与组成归因。

## 4. 不能推出什么

- 置换 p 是后验识别子池上的探索性诊断,不是确认性检验;exchangeability 仅在已选子群内;
- FGONLY 退出时仍是同技能运动学弱代理(EEF 同源、无接触力、无独立真值);
  "退出仍正"≠真握着;一切数值是复核优先级,不是 CONTINUE/动作收益;
- 匹配随机基线的格内正例率由同批 audit-only 标签离线计算,只用于研究标准化,
  不得流入在线排序或当任务先验部署;bootstrap 是描述性;
- n=19/单格增量 n 小,所有点估计脆弱;零训练、零阈值选择、零 Runtime 改动。
