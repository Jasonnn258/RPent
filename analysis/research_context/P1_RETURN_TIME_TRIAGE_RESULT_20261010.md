## 6. 机制结论(预登记两分支同时触发,如实分别记录)

**(A) 全局层——最小可证伪机制成立**:`LIFT_MINUS_GAP` 有预算选择性验证
(budgeted selective verification)。
- 机制陈述:对 pick 失败返回,"峰值抬升高且退出爪仍闭合"的样本占据复核预算时,
  退出时弱代理正例的命中率显著高于随机抽检。
- **对新 cohort 的可证伪预测**(下一轮直接检验,不回调参数):Top20% precision ≥ 2×
  池内基率;三任务各自 lift ≥ 2;episode 聚类 bootstrap 下界仍高于基线上界。
  任一不成立即机制被证伪。
- 它解释了为什么成立:退出持续漏报 92.3% 是 D-only(011 模式),而 011 的
  L∧G_final 已真——LMG 分数恰好就是"L 与 G 的连续强度",与该子群结构对齐。

**(B) 子池层——合法证据不足,如实报告负结果**:t9 D-only 池内 lift 仅 1.30,
**需要一种额外观测**:与工具返回**同刻**的物理/视觉证据(受控 lift probe 或
腕视图的目标在场/跟随判据),用于裁决"爪闭合+曾抬起"到"退出时仍持握"的边界。
静态末端阈值类证据在该子池**原理性不足**(与 VE-v0.1 的 gap 重叠区结论、
上轮几何不可分结论三方一致)。不强行制造正结果。

## 7. 不能推出什么

- 退出时 FGONLY 与 any-time 是**同一运动学弱代理的两个时点**,共享全部构念缺陷
  (EEF 同源、无接触力、无独立真值);"退出仍正"≠真握着、"排序高"≠该 CONTINUE;
- 本轮零阈值选择、零训练、零 Runtime 改动;103 例回顾性排序不能证明跨 cohort 或
  因果收益;bootstrap/jackknife 只是样本不确定性描述;
- t9 子池 n=19、t3 全局席位 2 席,小样本限制已在 §5 声明。
