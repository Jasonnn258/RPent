## 为什么需要这轮

全局合法返回证据排序在 Tool False 的103例上 Top20% precision=0.810，相对退出 FGONLY 基率0.252为3.21×。但 Task9 的 **D-only 子池19例** 本身有11例退出仍满足FGONLY、8例中途瞬时，已有 Top20% precision=0.750，只有1.30×。全局表现好可能主要来自**识别已知门槛分层（D-only）**，而非在困难且决策含糊的 D-only 内提供独立分辨。

研究问题：**在 Task9 D-only 内固定已知分层后，合法 Tool Return 的连续末端值还能否显著区分退出持续与瞬时？**

## 固定实验

脚本 `p1_task9_conditional_lab.py` 使用原 `p1_return_time_triage_lab.build_rows()` 数据资格与原冻结优先级。只在 `task=9 / gate_pattern=011 / tool.success=False` 这个既有19例子池工作，要求11个退出代理正例、8个代理负例。固定预算 Top4 和 Top8，比较：

- UNTARGETED（池内随机预算基线，precision基率11/19）
- PEAK_LIFT
- FINAL_GAP
- LIFT_MINUS_GAP
- D_ONLY_THEN_LIFT（池内D-only恒真，检验它是否退化为lift排序）

每一组计算实际TopK代理命中与proxy误选、相对池内基率的增益；在固定分数上仅置换proxy参考标签10,000次，估计单侧置换p值；逐个留出Episode给出TopK precision波动范围。并列采用预定均分法，不通过隐含ID打破并列，不对模型拟合参数。置换分析属于**后验选中的小子池探索性诊断**，不得解释为确认性统计证明。

**不能自动提高动作成功率的原因**：标签是技能返回时 FGONLY 运动代理，不是持握真值；当前用户未授权 L2 在线实验，也没有闭环 CONTINUE/RETRY 的物理 outcome。得分最高最多表示“更值得进一步核查”。

## 实验完成后的唯一科学分流

- **若池内Top4/8显著优于随机且留一Episode稳定**：继续用新的独立 cohort 做持久性验证，而非在相同19条样本上继续调阈值；探索是否能用已观测信息决定验证的优先级。
- **若池内效果不稳定或接近随机**：明确 STOP “仅合法末端静态证据能够解决复杂持握歧义”的方向；下一候选必须增加同一返回时刻的目标/爪指相对状态或短时序信息，并按物理动作/观测成本另行有界授权。已有Stage R中的原始RGB可探索视野覆盖，但不等于独立接触标签。
- **无论哪种结果**：不改变已经成立的**全局预算排序**这个探索性结果；不能把全局3.21×说成Task9子池也3.21×。保留数据样本单位、组间异质性和后验筛选局限。
