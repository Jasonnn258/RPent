### 修订 2:C2 拆为 Format-only 与 Swapped-history,重定义 H4 —— **接受**

- **修订前问题**:v1 的 C2 sham 一臂混装两种对照目的("注入格式本身
  有安慰剂效应"与"错误内容会误导"),且 H4 要求"错误历史 ≈ 无历史"
  ——这在"agent 真的利用内容"时会**必然失败**(错误历史应当主动
  误导,而非与无历史打平),判据自相矛盾。
- **修订后条款**(FINAL_DRAFT §0 H4 + §2 C2a/C2b 行):
  - **C2a Format-only**:注入机制开启,承载与 C4 **同格式**但所有
    交换事实槽位中性化的内容(只含"机械臂移动至中立点并返回、无物体
    交互"类中性条目)。检验:格式安慰剂。
  - **C2b Swapped-history**:注入**事实反转**的历史(A 前缀集注 B
    的关系事实,B 前缀集注 A 的),格式与 C4 全同。检验:内容敏感性。
  - **H4 重定义(不再要求错误历史=无历史)**:
    - **H4a(格式安慰剂,门)**:|C2a − B0| on L1 ≤ ε(建议起点
      10pp,DEV 定稿)。C2a 显著高于 B0 ⇒ 注入格式混杂,**全部收益
      不可解释 → STOP**。
    - **H4b(内容敏感性,方向性预期)**:预期 C2b **低于** B0
      (被错误历史主动误导,越信任历史偏离越大)。C2b ≤ B0−δ
      (建议起点 δ=10pp)⇒ 内容利用成立,强化 H2/H3 解释;C2b ≈ B0
      ⇒ "内容未被利用"如实报告(解释性降级,**非自动 STOP**);
      C2b 显著 > B0 ⇒ 异常信号,按混杂排查。
- **状态**:条款已写入;**ε/δ 待 DEV 校准**。

### 修订 3:C3/C4 严格区分 —— **接受**

- **修订前问题**:v1 两臂都写"重放帧 SAM3 导出",构造纪律未分写,
  存在"把人工整理的上界测成又一张手写卡、与 C4 的对比失去'上界 vs
  可实现'语义"的风险。
- **修订后条款**(FINAL_DRAFT §2):
  - **C3 Oracle-history = 历史信息上界**:只基于**合法视觉历史**
    (重放帧流 SAM3 导出 + 首帧空间锚),**允许人工核验与整理**——
    人工的角色是核验事实正确性(上界的定义就是"信息给足"),但:
    ① 只能核验/修正**合法来源可导出**的事实,不得添加任何视觉来源
    之外的信息;② 每一处人工修订必须留痕(与自动导出版本的 diff +
    溯源),使 C3−C4 差可分解(跟踪误差/压缩损失/人工整理三成分)。
  - **C4 Typed-state = 可实现 Typed Memory**:**全自动管线**:
    SAM3 跟踪 → 状态更新 → 压缩为 typed 关系(如
    `moved(bowl_from_cabinet, to=stove)`),离线**一次生成后冻结**,
    全程**零人工触碰**(Stage D sidecar 冻结纪律)。
  - **共同排除条款(两臂同罚)**:禁止读取 sim 隐藏真值、BDDL 实例
    ID、obj_of_interest、check_success 真值;合法来源 = 重放帧
    (SAM3 分割)、dump_state 级 state(EEF/夹爪/名字)、前缀动作流
    元数据(技能边界)。关系谓词用**空间起点标签**
    (bowl_from_cabinet)而非实例 ID——指令+真历史联合决定正确动作,
    全程不需要实例 ID。
- **残余风险(如实)**:C3(丰富叙述)与 C4(紧凑关系)**内容粒度与
  格式同时不同**,C3>C4 时无法立即区分"信息量"还是"格式";缓解 =
  C2a 格式对照统一兜底 + 留痕分解,列为 §四未解决风险 R4。

### 修订 4:指标修订(L1/L2/L3)—— **接受**

- **L1 首次目标选择正确率(主判,绑 H0/H1/H2/H3/H4a/H4b)**:
  - 定义:episode 内**首次使任一孪生碗产生 ≥ 位移阈值**(建议起点
    1cm,DEV0 噪声底定稿)位移的 pick 尝试,其所移动的实例是否 == 该
    前缀集+指令下的正确实例。仪器侧判定(sim_measurement 离线归因,
    planner 不可见),不依赖任务完成。
  - **无法判定(undecidable)的处理,三类分桶**:
    (a) 至 episode 结束无任何碗达到位移阈值(未发生有效 pick)
      → `L1_NO_EFFECTIVE_PICK`;
    (b) 单个 pick 窗口内两碗同时位移 → `L1_PROTOCOL_ANOMALY`
      (按 infra 纪律 ≤3 重试,仍现则该 episode 作废入 infra 账);
    (c) 归因证据不足以判定唯一实例 → `L1_UNATTRIBUTABLE`。
    (a)(c) **不计入分子也不计入分母,单独报告占比**;(b) 作废重试。
    **测量质量门**:undecidable 率 > 20%(建议起点,DEV 定稿)⇒ 仪器
    化不合格,先修仪器再谈判定(DEV0/DEV 阶段处理)。
- **L2 实例级 BDDL 任务完成率(check_success)**:实例级目标谓词
  (`On akita_black_bowl_1 plate_1`)自动判,**单独报告,不绑任何
  门**;次级分析 L2|L1-correct 条件成功率(执行环节纯度,与 C0 锚
  互证)。
- **L3 Stage Q 稳定抓取契约:**`stageQ_prereg.md` §2 双契约公式
  **逐字复用**(ACQUISITION:任一测量点 check_success ∨ FG 契约
  dz≥0.03 ∧ dxy≤0.10;STABLE:i*=首个 ACQUISITION 点 ∧ i* 至终点
  全测量点满足 ∨ 端点满足 ∧ (任一点 check_success ∨ i* 后测量点数
  ≥ HOLD_MIN_POINTS=4);基准 = 该 rollout 自己 pick 后测量),
  **仅作诊断,不设门**——用于区分"决策对但抓取不稳"与"决策错"。
- **H2/H3 主判绑 L1**:H2 = C3−B0(L1)≥30pp 且 C3 L1 绝对值 ≥85%;
  H3 = C4−B0(L1)≥15pp;L2/L3 单独报告(数值均为建议起点)。

### 修订 5:H1 判据细化(配对平衡/独立单位/CI/泄漏 STOP)—— **接受**
