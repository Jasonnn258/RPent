## 一、六项阻断项逐项修订

### 1. L1 双口径:全样本主判 + 可归因条件口径,杜绝选择性排除

**v2 缺陷**:[R] L1 只定义了可归因条件口径(undecidable 不计分子
分母)——若 undecidable 与臂相关(B0 困惑不 pick、C3 信息充足敢
pick),"分母存活率"本身被处理变量污染,**选择性排除**会系统性
扭曲臂间对比。

**修订条款**:
- **L1b(全样本口径,主判,H0-H4 一律绑 L1b)**:分母 = 该臂该批
  **全部采样 episodes**(扣 infra 作废且按 §1.3 替换规则补齐后的
  终版样本);分子 = 首次有效选择判对。**一切非"判对"结局(判错/
  无有效 pick/无法归因)一律计 0**——不排除、不加权。类比临床试验
  ITT(意向治疗)口径。
- **L1a(可归因条件口径,敏感性报告)**:分母 = 归因成功 episodes
  (即排除 `NO_EFFECTIVE_PICK` 与 `UNATTRIBUTABLE`);回答"agent
  动手时选得对不对"。**只报告不设门**;L1a 与 L1b 结论方向不一致时
  两口径并列报告并标记(说明 undecidable 驱动了结果)。
- **三类结局的显式处理(取代 v2 三桶)**:
  (a) `NO_EFFECTIVE_PICK`——至 episode 终无任何碗位移达阈值:
    **真实行为结局**,L1b 计 0,单独报占比;"无信息导致不动手"本身
    是历史对行为的因果效应的一部分,不得重试、不得剔除;
  (b) `UNATTRIBUTABLE`——发生了有效 pick 但归因证据不足(含单 pick
    窗口内两碗同时位移这类真实物理异常,如抓取时碰倒另一只碗):
    **真实行为/物理结局**,L1b 计 0,单独报占比,不重试;
  (c) **真实物理异常与 infra 的分界线(冻结)**:**仅**命中 infra
    指纹清单(rc≠0、env/服务崩溃 traceback、5xx/超时、工件缺失)
    才算 infra——**重试 ≤3,仍败则作废并同 cell 同臂补采 1 集**,
    补采入 infra 账(补采率 >10% 触发 infra 质量审查);**凡以结局
    内容定义的"异常"一律不是 infra**,不重试不剔除。
- **测量质量门收窄**:20% 上限只适用于 `UNATTRIBUTABLE` 占比
  (仪器归因能力);`NO_EFFECTIVE_PICK` 占比不设门(它是被测量
  量本身,高占比是发现不是仪器故障)。
- **L1 判定时机(写死)**:episode 内**首次使任一孪生碗位移 ≥
  阈值(起点 1cm,DEV0 噪声底定稿)的 pick 尝试**;位移阈值以下的
  微动不算;判定一律仪器侧(sim_measurement 离线归因),planner
  不可见,不采用 pi0_pick 自报 success。

### 2. H1 统计重写:cell 级检验 + Wilson 相容性核查 + 功效分析

**v2 缺陷**:①"B0 点估计 ≤50% 且单侧 Wilson CI 上界 ≤60%"在
建议样本量下**统计上不可行**(见下);②未指明聚类相关下的检验
统计量;③无功效分析。

**精算(本节为冻结依据,单侧 95%,z=1.645)**:
- Wilson 上界 @ p̂=0.50:n=48 eps → **61.6%**;n=68 → 59.8%才
  首次 <60%。即:24 cells(48 eps)**即便 B0 恰在机会水平,期望
  上界也超 60%,门必挂**;再计 cell 内相关(同 cell 两 episodes
  共享同一次 PREFIX 重放,有效样本 < 名义),实际更宽。
  **结论:v2 的 60% 上界门不可行,废除。**
- 可检出效应(80% 功效,单侧 5%,cell 级配对差):Δ=2.485·SD_d/√n:
  | n_cells | SD_d=0.30 | 0.35 | 0.40 | 0.45 | 0.50 |
  |---|---|---|---|---|---|
  | 24 | 15.2pp | 17.8pp | 20.3pp | 22.8pp | 25.4pp |
  | 32 | 13.2 | 15.4 | 17.6 | 19.8 | 22.0 |
  | 40 | 11.8 | 13.8 | 15.7 | 17.7 | 19.6 |
- 所需 cell 数 n=(2.485·SD_d/Δ)²:H2(30pp)需 6-14 cells
  (SD 0.30-0.45)——**24 cells 充足**;H3(15pp)需 **25-56
  cells**(SD 0.30-0.45)——**24 cells 仅在 SD_d≤0.29 时达标**;
  H4a 显著性检验按 §一.3 的"显著性∧效应"双条件控制假阳,不单独
  受此表约束。

**修订条款(H1 检验程序,冻结)**:
- **独立单位 = cell = (task_variant, seed)**;每 cell×臂恰有
  A/B 两 episodes;cell 内相关由 cell 级聚合吸收。
- **H1 资格判据(取代 v2 ①②)**:
  (i) B0 的 **L1b cell 均值点估计 ≤ 0.50**;
  (ii) **cell 级单侧符号检验不显著**(cells 按 cell 均值分
    ">0.5"与"<0.5"两阵营,恰 =0.5 的平局 cell 剔出检验但不剔出
    点估计;H0: p(>0.5)≤0.5,leak 判定 = p<0.05 拒绝);
  (iii) **前缀集正交检验**:B0 在 A 集与 B 集的 L1b cell 均值差
    的 cluster-bootstrap 单侧 95% CI 上界 ≤ +10pp(起点)。
  三条全过 = H1 过;(ii) 违 → 任务泄漏 STOP;(iii) 违 → 物理
  残差通道泄漏 → 审计二 §三后备,仍不过 STOP。
- **CI 一律描述性报告**(episode 级 Wilson / cell 级 bootstrap
  95%),不设门——门的职能全部由上述检验承担。
- **符号约定冻结**:配对差一律"臂X − 臂Y"按 §五门表列出的臂序,
  分析脚本注释写明方向;cluster bootstrap ≥10000 次,重抽 cells。
- **变异体分层**:task_variant 只有 2 个,bootstrap over cells 不
  能覆盖 variant 级聚类——**按 variant 分层报告**为主、合并为辅;
  结论边界受限如实写(REVIEW R6 延续)。
- **n 的冻结决策规则(DEV 后)**:DEV 估计 SD_d 后按上表定 n:
  SD_d≤0.30 → n=24 cells 可保 H3;0.30<SD_d≤0.42 → **提 n 至
  ≥(2.485·SD_d/0.15)² 向上取整(典型 34-44)**;SD_d>0.42 →
  与用户复议(H3 门 15pp→20pp 或再提 n,**只能选其一,不得双改**)。
  H2 门 30pp 在全部 SD 情形下 24 cells 均充足。

### 3. C2a 净化:零真假断言 + 跨臂字节一致

**v2 缺陷(本轮自查发现)**:v2 的 C2a 中性内容写有"无物体交互"
类条目——这在 **A 前缀集为假、B 前缀集为真**,即 C2a 文本随臂
变化真假性 = **携带与前缀集相关的差分信息**,不是纯格式对照;
且若 A/B 集文本不同字,还构成前缀集指纹。

**修订条款(C2a 构造纪律,冻结)**:
- C2a 文本在**同 cell 的 A/B 两集间字节一致**(同一份冻结文件,
  不随臂/集变化);
- 内容只允许两类元素:①**结构元素**(C4 同款模板/字段名/层级/
  时间戳格式);②**双前缀下同真的非恒等命题**——允许的语义域
  封闭为:"机械臂执行了 setup 阶段动作""夹爪发生开合""机械臂
  返回 home 位"——这些在 A(两次 pick-place+homing)与 B(中立
  往返+homing)下均为真,且不含任何碗状态/身份/位置/方向断言;
- **禁止出现**:碗/盘/柜/灶等 C4 槽位名词、任何 moved/relocated/
  position 类谓词、"无物体交互"式否定断言、任何随臂变化的计数值;
- **冻结前双重验证**:①自动检查——C2a token 集与 C4 实际填充
  槽位词表交集 = ∅,且 A/B 集文件 sha256 相同;②人工签核——冻结
  清单加一条 reviewer 项"C2a 无交换事实相关真假断言"。
- C2b(Swapped-history)保持 v2 定义:事实反转、格式与 C4 全同,
  作为**错误历史负对照**(H4b 方向性预期"被误导 < B0"),本项
  无修订。
- **H4a 判定程序(细化)**:STOP 需**双条件同时**:C2a−B0 的
  L1b cell 级配对检验单侧 p<0.05 **且** 点估计差 > ε(10pp 起)。
  只满足显著性不满足效应量(或反之)→ 报告并标记,不 STOP。

### 4. H0/H2 门槛适配:执行天花板不得污染历史充分性判定

**v2 缺陷**:H2 的"绝对值 ≥85%"来自"信息完备的 2 选 1 应接近
全对",但 **L1b 含执行环节**(选对→伸手→抓住→位移达阈值),
天花板被 Pi0.5 执行噪声压住:若系统真实可执行上限是 78%(C0 水平),
C3 永远到不了 85% → H2 以"历史不充分"名义记录一次**执行能力
失败**,判定污染。

**修订条款(冻结)**:
- **C0 双角色**:①能力地板(H0:池化 L1b 点估计 ≥65%,分前缀集
  各 ≥50%;**0.60≤点估计<0.65 为边界带 → 携 DEV 数据提交用户
  裁决,不自动 FAIL**;<0.60 自动 FAIL——精算依据:真实 p=0.70
  时点估计门 0.65 的假阴率 22.5%,边界带吸收之);②**同批执行
  天花板参照**(C0 与所有臂同 TEST 批跑,执行条件同时同地)。
- **H2 绝对值门改写**:`C3_L1b ≥ min(0.85, C0_L1b − 0.05)`。
  - C0 ≥ 0.90 → 门 = 0.85(原门绑定,直觉情形);
  - C0 < 0.90 → 门 = C0−0.05("oracle 历史须把系统带到显式位置
    指令可达水平的 5pp 以内")——**天花板由同批实测校准,不再
    假设**。
- **H2 判定完整式**:H2 过 ⇔ (C3−B0 配对差 ≥30pp 且检验显著)
  ∧ `C3 ≥ min(0.85, C0−0.05)`。C3 < C0−0.05 的情形如实解释为
  "历史→决策的翻译/呈现损失超容差",走 v2 判定矩阵"H2 不过"
  分支(审计二 §三 STOP 复核),**不得**以执行噪声豁免。
- H3(15pp)为纯配对差,**天花板在对比中自动抵消**,不改写;
  其功效问题见 §一.2 的 n 决策规则。
- H4a/H4b 均为臂间对比,同上不改写。

### 5. 执行次序锁定与防回看

**冻结次序(不可换序)**:
1. **协议预锁**(本批两份文档 + v2 + REVIEW 构成 DEV0/DEV 协议
   基线;本文件即预锁产物)→
2. 用户批准 DEV0 → **DEV0 执行**(按 `S1_DEV0_APPROVAL_SPEC.md`,
   只产仪器资格与阈值建议,不产任何判定)→
3. **DEV 校准**(只做三件事:§一.2 的 SD_d 估计与 n 定稿、§五
   全表数值定稿、L1 位移阈值/undecidable 上限按 DEV0 噪声底落定)→
4. **冻结 TEST 预注册**(数值定稿 + 分析脚本哈希冻结后,用户批准
   才冻结;Stage G0.6 先例)→
5. **TEST 一次跑**(判定只看 TEST)。

**防回看条款(冻结)**:
- DEV 数据永不进判定;DEV0/DEV 结果不得用于**收紧**正式门
  (收紧 = 用数据把门修得对自己有利,禁止);**放宽**仅限 §一.2
  预登记的 n/H3 决策规则与 §一.4 边界带程序,且必须记 deviation
  (旧值/新值/依据/日期)并经用户批准;
- TEST 开跑后发现的任何门槛问题:如实报告,门槛不动;确需改门 →
  只能适用于**新的独立 TEST 批**(新 seed 批 + 重新冻结),原批
  结果按原门报告;
- 分析脚本(L1b/L1a/L2/L3 计算 + §一.2 检验 + bootstrap)在冻结
  步与预注册同 commit 哈希存证,TEST 后不得改;改 = 新批重跑。
